<!-- Code spans, escapes, entities, long span. -->

A code span `keeps  inner   spaces` and an empty-looking span of one space: ` `.

Escaped emphasis \*not emphasis\* and an escaped bracket \[not a link].

Entities: `&amp;` `&lt;` `&#39;` `&#x2A;`.

Double-backtick span that contains a backtick: ``a`b``.

A long code span that prettier will not wrap: `this_is_a_single_token_that_is_longer_than_forty_columns_and_also_longer_than_eighty_if_I_keep_going_xxxxxxxx`.
