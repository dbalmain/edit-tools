Where we disagree with the reference formatter

One row per language. A discrepancy is one corpus file at one width whose output differs from the reference formatter's, and every one is counted — an approved divergence is a decision, not an absence. The three columns that split them are the interesting part: accepted carries a reviewed verdict, excluded is a file the reference rewrites in a way gate 3 cannot call equivalent and so can never be reviewed, and open is what is left. Only the last column is work.
